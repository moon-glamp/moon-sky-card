# Moon Sky Card v2

Рабочий серверный пакет для Moon Observatory.

## Уже реализовано

- админ-страница сотрудника;
- PIN-вход;
- создание карты по имени, дате и времени;
- ручная отметка фактически наблюдавшихся объектов;
- уникальный ID каждой карты;
- SQLite-база всех созданных карт;
- расчёт положения ярких звёзд для заданных координат;
- генерация фирменного PDF A4;
- настоящий QR-код в PDF;
- публичная мобильная страница каждой карты;
- кнопка скачивания PDF;
- история последних карт;
- Dockerfile и docker-compose для размещения на VPS.

## Быстрый локальный запуск

Установите Python 3.11+.

```bash
pip install -r requirements.txt
python app.py
```

Откройте:

`http://127.0.0.1:8000/admin?pin=2468`

После создания карты появится ссылка:

`http://127.0.0.1:8000/sky/УНИКАЛЬНЫЙ_ID`

На одном компьютере это работает сразу.

## Почему QR с локальным адресом не открывается на телефоне

`127.0.0.1` означает "это устройство". Поэтому QR, созданный локально, доступен только на самом сервере.

Чтобы QR открывался у гостя на iPhone/Android, разместите сервис в интернете и задайте:

`BASE_URL=https://sky.ваш-домен.ru`

Например после подключения поддомена:

`BASE_URL=https://sky.moonglamp.ru`

Тогда QR автоматически будет вести на настоящую публичную страницу.

## Размещение на VPS через Docker

1. Установить Docker.
2. Скопировать папку проекта на сервер.
3. В `docker-compose.yml` заменить:
   - `BASE_URL`
   - `ADMIN_PIN`
   - координаты при необходимости.
4. Запустить:

```bash
docker compose up -d --build
```

5. Настроить Nginx и HTTPS для поддомена.

## Что остаётся вне этого пакета

Самостоятельно выполнить DNS-настройку домена и фактическое размещение на вашем сервере я не могу без доступа к нему.

## Важное ограничение астрономии

Версия v2 рассчитывает положение каталога ярких звёзд. Луна/планеты в интерфейсе сейчас указываются как фактически наблюдавшиеся объекты. Для научно точного автоматического положения Луны и планет нужен следующий модуль эфемерид (например Skyfield + локальный JPL ephemeris).

## Файлы

- `docker-compose.yml` — простой запуск;
- `nginx_example.conf` — пример прокси;
- `.env.example` — настройки.
